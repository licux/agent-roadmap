## ファイルの命名規則

```
p<書籍の対象ページ（0埋め3桁）>_<種別>.md
```

例: `p090_update.md`、`p102_note.md`、`p245_errata.md`

- 種別は `update` / `note` / `errata` の3種類です（`update` の綴りにご注意ください）。
- 同じページ・同じ種別で複数の項目がある場合は、1つのファイル内に見出しを分けて記載します。ファイル名に連番は付けません。一覧には項目ごとに行を分け、それぞれの見出しにリンクします。
- 複数のページにまたがる項目は、主たるページのファイルに記載します。一覧では、関係する各ページから同じファイルを参照します。
- 特定のページに紐づかない項目（サンプルコードのリポジトリ更新、本書全体に関わる注記など）は `p000_<種別>.md` に記載します。
